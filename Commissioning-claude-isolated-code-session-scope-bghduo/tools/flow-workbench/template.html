Flow Operations Workbench

Repository request shapes, embedded, validated, probed and exportable.

Repository alignment scope

The workbench embeds the complete trigger JSON Schema and flattened field definition for every catalogued flow. Each one carries the path and SHA-256 of the definition file it was extracted from, so any entry can be traced back to the repository.

Flows whose trigger is Request/PowerAppV2 are excluded at build time: they are invoked by Power Apps through the Power Platform connector rather than by posting to a URL. Every remaining flow is enabled for composing, validating and sending.
