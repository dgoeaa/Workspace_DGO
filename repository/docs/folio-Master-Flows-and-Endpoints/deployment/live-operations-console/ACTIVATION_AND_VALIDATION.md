# Activation and Validation

1. Extract the ZIP completely.
2. Open `index.html`. The console can also run when only `index.html` is copied because the operational model is embedded.
3. Confirm bottom-right status: `ACTIVE · SELF-CONTAINED`.
4. Confirm initial dashboard: Actions 14; Closed 0; Critical open 10; Missing parameters 18; RN accepted 0/38; progress 0%.
5. Open Execution and confirm OP-001 through OP-014.
6. Open Parameters and confirm all 21 fields, including three locked repository values.
7. Open 38 RN Acceptance and confirm RN-001 through RN-038.
8. Open Release Gate and confirm NO-GO.
9. Run Structural Audit. Missing tenant inputs should be reported; initialization errors should not.
