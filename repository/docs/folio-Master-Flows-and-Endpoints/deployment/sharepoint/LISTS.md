> Generated by `scripts/build-estate-docs.mjs`. Do not edit by hand —
> run `npm run estatedocs`. `npm test` fails if this file has drifted from the specs.

Two estates share one tenant and never share a list. The portal estate is reached by
anonymous callers with no session; the governance estate is reached by authenticated NITDA
staff. Exactly one crossing between them is designed, and it is named at the end of this
page. A third set of lists — the HTTP flow registry — is specified but not yet built, and
is listed apart from both for that reason.

list and field counts so a run can check its own work. `CaptureRequestBody` and
`CaptureHeaders` are seeded false, and that is what keeps request payloads out of the ledger.

## The one designed crossing

`ECM_DOCS_INTAKE` reads `Portal Registry`.
It is tenant-authenticated and read-only, and it is the only place the internal platform is
permitted to touch the portal estate.
